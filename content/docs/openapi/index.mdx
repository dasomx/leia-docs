The LEIA Partner API enables institutions to build complete courses programmatically — from parsing descriptions through generating content, slides, and video exports.

![Server-to-server integration: Your App → Partner API (api.leia.to) → LEIA Platform](/partner-api.png)

## Authentication

All requests require a LEIA API key with the `leia_sk_` prefix:

```
Authorization: Bearer leia_sk_...
```

API keys are scoped to a single organization and service user. Create and manage keys from the LEIA Creator Dashboard under **Workspace → API Keys**.

## Rate Limiting

- The default is **1,000 requests per API key**, with a **one-hour inactivity reset**. Individual keys can have different saved limits.
- The counter resets after more than one hour since the last counted request, not at the start of each clock hour. Continuous polling can accumulate requests across several hours.
- Job polling, discovery, and generation share the same allowance. On HTTP `429` with code `RATE_LIMITED`, pause requests; rejected requests do not extend the reset interval.
- Rate-limit headers are not currently returned. Contact LEIA with your organization or API key display name to confirm a key's settings. Do not send the secret key.

## Idempotency

Mutation endpoints support the `Idempotency-Key` header for retries of the same request. Idempotency records expire after 24 hours; this is separate from API key expiry.

## Base URL

```
https://api.leia.to/api/v1
```

## Templates, voices, Blueprint, and Learning Bits

Discover available values before starting generation:

- [Slide templates](/docs/openapi/listSlideTemplates): active organization templates, with `ILLUSTRATED` and `HTML` options.
- [Narration voices](/docs/openapi/listNarrationVoices): Gemini voices; pass the returned `value` as `options.voice`.
- [Design Blueprint generation](/docs/openapi/generateCourseDesignBlueprint) and [saving](/docs/openapi/saveCourseDesignBlueprint): define the design used by HTML slides.
- [Learning Bits](/docs/openapi/listCourseLearningBits): list sets, [create drafts](/docs/openapi/generateLearningBitDraftSet), and [render a set](/docs/openapi/renderLearningBitSet).

See the [content generation guide](/docs/content-generation) for the request sequence and examples. The [live OpenAPI specification](https://api.leia.to/api/v1/openapi.json) is also available as JSON.
